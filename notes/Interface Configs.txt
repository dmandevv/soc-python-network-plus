Speed and duplex:
- 10/100/1000/10 Gig
- Duplex: Half/Full
- Automatic and manual
- Needs to match on both sides

IP address management:
- Layer 3 interfaces
- VLAN interfaces
- management interfaces
- IP address, subnet mask/CIDR block, default gateway, DNS

Port bonding / Link aggregration (LAG):
- multiple interfaces act like one big interface
- won't cause a loop if configured properly

Link Aggregration Control Protocol (LACP):
- adds automation and management

Maximum Transmission Unit (MTU):
- max size IP packet to transmit, not fragment
- fragmentation slows things down, a single lost fragment makes the entire packet useless

Jumbo frames:
- ethernet frames up to 9000 bytes
- increased packet size -> fewer packets to switch/route
- if device doesn't support Jumbo frames, it will drop packet!
