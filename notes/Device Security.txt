Port Security: Prevent unauthorized users from connecting to a switch interface
    - alert sent out or disables port
    - based on source MAC address
    - each port has its own config

1. configure a maximum number of source MAC addresses on an interface
2. the switch monitors the number of unique MAC addresses (keeps a list)
3. once limit is exceeded, Port Security activates (alert can be sent, default is to disable interface)

MAC filtering:
- limit access by physical MAC address
- attackers can spoof -> packet capture, read valid MAC address, change software on their Network adapter to show the captured MAC address, now impersonating the device
