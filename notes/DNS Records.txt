Resource Records (RR):
- IP addresses, certificates, host alian names

Start of Authority (SOA) at start of file:
- describes DNS zone details
- structure:
    - name of zone
    - serial number
    - refresh, retry, and expiry timeframes
    - caching duration/TTL

Address Records (A) (AAAA):
- defines the IP address of a host
- A for IPv4
- AAAA for IPv6

Canonical name records (CNAME):
alias for another Canonical name
another way to reference a domain

chat IN CNAME mail.example.com
ftp  IN CNAME mail.example.com
www  IN CNAME mail.example.com


Mail exchanger record (MX):
determines the host name for the mail server


Text records (TXT):
human readable public information

    SPF protocol (Sender Policy Framework)
    - prevent mail spoofing
    - mail servers check that incoming mail, did it really come from an authorized host

    Domain Keys Identified Mail (DKIM)
    - digitally sign your outgoing mail
    - validated by the receiving mail server
    - validation done by referencing public key in DKIM TXT record


Name server records (NS):
- lists the name servers for your domain

Pointer record (PTR):
- reverse of an A or AAAA record
- gives IP for a host name
