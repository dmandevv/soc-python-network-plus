Routing Tables:
- identify destination IP address (it's in the packet)
- check if dest. IP is on a locally connected subnet and forward it if it is
- otherwise, forward to the next hop router/gateway

Static Routing:
- define the routes

Advantages
- easy to configure/manage on smaller networks
- no overhead from routing protocols
- easy to configure on stub networks (only one way out)
- more secure - no routing protocols to analyze

Disadvantages
- difficult to manage on larger networks
- no automatic method to prevent routing loops
- if there's a network outage, you need to manually update the routes
- no automatic rerouting
