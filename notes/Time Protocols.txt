Network Time Protocol (NTP):
- synchronizes clocks on every device
- automatically done
- accurate to the millisecond

NTP Server:
listens on UPD/123, responds to time requests from NTP clients
doesn't modify its own time

    NTP Client:
    requests updates from NTP server
    NTP client/server:
    both in one 
    Can host your own NTP server


Network Time Security (NTS):
NTP sends traffic in clear
wrong time can cause issues
NTS is NTP updated with authentication

NTS Key exchange server:
1. TLS handshake between Client and NTS-KE server
2. Client requests cookie from NTS-KE server
3. Client makes NTP request (cookie included) to NTP server
4. Client receives NTP response from NTP server

Precision Time Protocol (PTP):
- more precise, down to nanosecond (needed for industrial apps, financial trading)
- specialized hardware, avoids delays of OS and applications
