Using the correct fiber optics:
    Multimode fiber: light can bounce and take many differents paths
    Single mode fiber: smaller diameter, light bounces much less

    Size: 50/125 Multimode, 62.5/125 Multimode, 9/125 Single mode
    Fiber and frequencies must match equipment


Cable categories:
    Telecommunications Idustry Association (TIA) sets the standards

    Speed/bandwidth: theoretical maximum data rate (bits per second) - Size of the pipe
    Throughput: amount of data transfered in given timeframe (bits/bytes per second) - How much water is in pipe
    Distance: maximum distance before signal is lost (vaires for copper, fiber, repeaters)

    Validate the cable:
        - is it installed correctly
        - use a cable tester


Unshielded Twisted Pair (UTP):
- wires twisted together in pairs (+/-) - twist ensures both wires are equally exposed to interferance so noise can be cancelled out at receiver
Shielded Twisted Pair (STP):
- same as UTP, but each wire/cable is covered in either an aluminum foil or braided copper mesh
- cable needs to be grounded (includes grounding wire)

Crosstalk (XT):
- signal on one circuit affects another circuit
- XT measures how much signal is leaking

    Near End Crosstalk (NEXT): interferance measured near the transmitter
    Far End Crosstalk (FEXT): interferance measured away from transmitter
    Alien Crosstalk (AXT): interferance from other cables
    Attenuation to Crosstalk Ratio (ACR): difference between insertion loss and NEXT
        Measured as Signal-to-Noise Ratio (SNR) - e.g. 10:1 is good, signal is 10 times clearer than noise
    
    Troubleshooting Crosstalk:
        - punchdown/connectors busted
        - maintain twists
        - increase distance between wires (add a spacer inside cable)
        - test installation

Cable handling:
- no twisting, pulling or stretching
- watch bend radius
- no staples, use cable ties
- keep away from power cords, fluorescent lights, electrical systems, fire systems

Attenuation:
- over distance and through mediums

Improper termination:
- mismatched pins can lower performance or cause connectivity issues

Wiring mistake:
- crossed wires (cable ends, punchdowns)
- check a wire map to identify
- some network interfaces automatically correct (Auto-MDIX)
