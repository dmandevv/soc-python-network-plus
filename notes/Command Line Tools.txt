ping:
- uses ICMP
- test round-trip time

traceroute:
- determine route packet takes to destination
- map entire path
- uses ICMP TTL Exceeded error message
    - number of hops, not time
    TTL=1 for first router, TTL=2 for second
    Some firewalls filter ICMP
    ICMP is low-priority protocol

nslookup and dig:
- lookup info for DNS servers
- Canonical names, Ip addresses, cache timers
- nslookup is deprecated, use dig instead
- Domain Information Groper (dig)

tcpdump:
- capture packets from command line
- apply filters, view in real time
- save the data, use in other applications
- saved in "pcap" format

netstat:
- network statistics
- netstat -a: shows all active connections

ipconfig/ifconfig/ip:
- determine TCP/IP and network adapter info
