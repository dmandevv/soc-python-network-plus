Switching Loops:
- Spanning Tree Protocol needed to prevent packer Loops
- switches forward traffic to MAC address
- Broadcast and multicast frames can be sent out every other interface on switch 
- IP has TTL to stops loops, but what about MAC?

Spanning Tree Protocol (STP):

Root port: single best path from a non-root switch to the root switch
Designated Port: one of many forwarding ports aside from root port

Blocked Port: not forwarding to prevent a loop
Listening Port: not forwarding and cleaning the MAC table (waiting for BPDU frames from other switches)
Learning Port: not forwarding and building the MAC table (using data from BPDU frames)
Forwarding Port: data passes through as normal
Disable Port: admin turned port off

Switches send a reserved Mac-layer multicast (01:80:C2:00:00:00) containing a:
    Bridge Protocol Data Unit (BPDU) frame 
    - share topology data, calculate paths, and maintain the tree
    - alert other switches when a link goes down or changes state
    - sent every 2 seconds, link is considered down if it misses 3 updates (6 seconds)
    - SPT will change topology of path
    - switches receive these frames, but don't forward them

    Root bridge selection:
    - selected at startup, decided by all bridges
    - can be manually configured: lowest bridge ID is selected
    - if there's a tie: device with lowest MAC address is chosen

VLAN assignment:
- device is connected and has an IP, but can't connect to other devices?
- check the specific switch interface's VLAN assignment is the same as your devices

ACLs can break networks:
- clients are working, DHCP is assigning properly, routing tables look good
- but packets are dropping
- check the ACLs

ACL best practice:
- top to bottom, granular to broad
- Before editing an ACL, disable it on that interface
- e.g. you didn't disable the ACL on the interface, you add a new blank list, and now you can't access the switch
- what happened was the newly added ACL implicitly denies all traffic by default, including you accessing the switch of that interface
