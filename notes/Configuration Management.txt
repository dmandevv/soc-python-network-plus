Production Configuration:
- most current running config 
- covers all aspects of changes:
    - hardware devices and firmware versions
    - device driver versions
    - application software versions
- Usually tested before installation

Backup Configuration:
- always need a Backup
- make one before any change
- copy files, create snapshot of a VM, etc.

Baseline/golden Configuration:
- all applications must follow this Baseline
- Firewall settings, patch levels, OS file versions
- constant updates

Integrity measurement check for secure baseline:
- ensure devices are compliant with this baseline config
- either force device config to conform, or update golden image to adapt to changing environment
