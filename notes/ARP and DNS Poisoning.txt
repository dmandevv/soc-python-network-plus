ARP poisoning (IP spoofing):
- client wants to communicate with a device, but doesn't know it's MAC address, only IP address of router
- send an ARP Request to the router, which will do an ARP broadcast to find the device with that MAC address and return its IP address
- store this info in ARP cache

- attacker can send an ARP Response spoofing the routers IP address, but with the MAC address of the attackers device
- client now sends all requests intended for router to the attacker


DNS poisoning:
- modify the DNS server OR the clients host file
