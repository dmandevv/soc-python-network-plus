Ethernet Media Access Control address:
"physical" address of a network adapter
48 bits / 6 bytes / 6 octets (each octet is 8 bits exactly, always, unlike bytes which can be different in special cases)

First 3 bytes are the Organizational Unique Identifier (OUI):
- shows who built the device, the manufacturer
Last 3 bytes are the Network Interface Controller-Specific (NIC):
- serial number for the device (burned in address)

LAN switching:
- forward or drop frames based on destination MAC address
- builds a constantly updating list by incoming MAC addresses of traffic
- use SPT to prevent loops

MAC flooding:
- MAC tables have a size limit
- attacker can send traffic with different source MAC addresses
- the table fills up
- traffic is now sent to ALL interfaces
- attacker can now capture all network traffic
- flooding can be restricted in the switches port security settings
