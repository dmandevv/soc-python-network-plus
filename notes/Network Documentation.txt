Physical Network Map:
- follows the physical wires and devices
- rack locations

Logical Network Map:
- use software (Visio, OmniGraffle, Gliffy)
- high level layout (WAN, application flows)
- used for planning and collaboration

Rack Diagrams:
- access to data center might be limited
- this diagram can be used to guide someone inside to exact locations
- Rack W in row 3, unit 15 needs server reset

Cable maps and diagrams:
- physical cables and fibre
- planning installation, numbering each network drop, troubleshooting

Network diagrams:
- show layer 1, 2, 3 on each switch/router

Asset Management:
- record of every Asset
- associate support tickets with exact device and model
- financial records, audits, depreciation, purchase date (warranty still valid?)
- asset tag (Barcode, RFID, visible tracking number, org. name)

Asset Database:
- central asset tracking system
- assigned users: associate a person with an asset
- warranty tracking
- software licenses, renewal deadlines

IP Address Management (IPAM):
- plan, track, configure DHCP
- report on IP Address usage
    - time of day, user-to-IP mapping
- control DHCP reservations
- manage IPv4 and IPv6 from one console

Service Level Agreement (SLA):
- minimim terms for services provided
- uptime, response time, 99.99%
- "No more than 4 hours of unscheduled downtime"

Site Surveys:
- determine existing wireless landscape
- identify access points
- work around existing frequencies
- ongoing process, sites change over time
- Heat Map: identify wireless signal strength
