Flow data:
- gather traffic statistics from all traffic flows

Netflow:
- standard collection method
- collects traffic data, not packet deep application data

Probe watches network communication:
- Tap: physical device that splits signal to copy 100% of traffic
- SPAN (Switched Port Analyzer): port mirroring, software feature on a managed switch that copies traffic from specific ports

Collector receives records:
- usually contains a reporting app to summarize/visualize data

 Protocol Analyzer:
 - gather frames on the network
 - view traffic patterns
 - verify packet filtering and security controls
 - large scale storage

 Network performance baseline:
 - after gathering all this data, we can build what a "normal" day on the network looks like
 - set a baseline, compare traffic to baseline
 - SIEM

 Syslog:
 - aggregation of diverse message logging in central place (usually a SIEM)
 - logs ware labelled: facility code (program that created it) and severity level

 Getting the data (sensors and logs):
 - data is sent to SIEM
 - operating systems
 - infrastructure devices
 - Netflow sensors

API integration:
- automate the command line
- batch processes

Port mirroring:
- copy traffic from one or more interfaces
- packet captures, IDS, performance monitoring
- mirror traffic from one switch to another
