
Four important addresses:

1. Network adress/subnet ID
- first address in the subnet

2. Broadcast address
- last address in the subnet

3. First available host address
- One more than the network address

4. Last available host address
- One less than the Broadcast address


Magic Number subnetting (Convert subnet mask to decimal)
1. Identify interesting octet
2. Calculate the magic Number
- 256 minus interesting octet
3. Calculate host range
4. Identify the network address
- First address in range
5. Identify the Broadcast address
- Last address in range


PRACTICE 1
IP address: 165.245.77.14
Subnet mask: 255.255.240.0

Mask:      255  255  240  0
Action:    COPY COPY      ZERO
IP:        165  245  77   14
Subnet ID: 165  245       0

interesting octet is 240
256-240=16
Magic number is 16
So subnet would have max 16 hosts

Mask:      255  255  240  0
Action:    COPY COPY 16   ZERO
IP:        165  245  77   14
Subnet ID: 165  245  64   0

Find broadcast ID: Subnet ID + Magic number - 1

IP address: 165.245.77.14
Subnet mask: 255.255.240.0
Subnet ID: 165.245.64.0

Mask:                   255  255  240  0
Action:                 COPY COPY 16   ZERO
Subnet ID:              165  245  64   14
Broadcast Address:      165  245  79   0

Broadcast Address: 165.245.79.0

First host: 165.245.64.1
Last host:  165.245.79.254




PRACTICE 2

IP Address:  10.180.122.244
Subnet Mask: 255.248.0.0

Subnet ID: 10.xxx.0.0
Magic number=256-248=8

IP: 180 is in block 8 (magic number)
Block 8 starts at: 176

Subnet ID: 10.176.0.0

Broadcast Address: 10.xxx.255.255
Magic number=256-248=8
176+8-1=183

Broadcast Address:
10.183.255.255

First available host: 10.176.0.1
Last available host:  10.183.255.254
