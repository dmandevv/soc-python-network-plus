# 4.3 — Given a scenario, apply network security features, defense techniques, and solutions

Where [4.1](4.1-security-concepts.md) is vocabulary and [4.2](4.2-attacks.md) is what goes wrong, **4.3 is the countermeasures** — and the exam phrases it as *"given a scenario,"* meaning questions describe a situation and ask which control fits.

**Official term list:**

- Device hardening — disable unused ports and services · change default passwords
- Network access control (NAC) — port security · 802.1X · MAC filtering
- Key management
- Security rules — access control list (ACL) · URL filtering · content filtering
- Zones — trusted vs. untrusted · screened subnet

---

## Device hardening

**Reducing a device's attack surface by removing what it does not need.** The principle: every enabled feature is a potential way in, so anything without a purpose gets turned off. This is the *default configuration is not a secure configuration* idea made concrete.

### Disable unused ports and services

Two different meanings of "port", and the exam uses both:

| Kind | Example | How it is disabled |
|---|---|---|
| **Physical port** | An empty switch port in the wiring closet | `shutdown` on the interface |
| **Logical port / service** | Telnet on 23, HTTP on 80, an unused management daemon | Stop the service, or block the port |

**A live switch port with no cable is a network jack for anyone who reaches it.** It hands out a lease, joins its VLAN, and forwards traffic — no authentication involved. The same logic applies to a running service nobody uses: it can still be exploited, still needs patching, and still appears in a scan.

**The counterargument is convenience**, and it is why this finding is so common: an administrator pre-configures ports for future use, and the future never audits them.

### Change default passwords

Default credentials for every consumer and enterprise device are published, searchable and indexed. Shodan and similar services list internet-exposed devices by model, which is enough to try the vendor default against them at scale.

**This extends past the admin login** — SNMP (Simple Network Management Protocol) community strings `public` and `private`, default wireless keys printed on a label, and vendor service accounts all count. **The Mirai botnet was built almost entirely on a list of about sixty default username/password pairs.**
