Access Control Lists (ACL):
- allow/disallow traffic
- source IP, Destination IP, port, time of day, application
- Restrict access to Network devices, limit by IP address
- implemented by firewall, router, OS policies


URL filtering:
- allow/block individual URLs
- block by category (auction, travel, NSFW, malware)
- part of NGFW


Content filtering:
- control traffic based on data within the Content


Screened Subnet:
- separated network from private interal one 
- public webservers and email servers

Security Zones:
- each area of network must be labeled with a "zone" (e.g. trusted, untrusted, internal, external, Internet, Servers, Databases)
- simplifies security policy:
    - Trusted to Untrusted (allow)
    - Untrusted to Screened (allow)
    - Untrusted to Trusted (deny)
