The Ethernet frame:
    1. Preamble: 7 bytes: 56 alternating 0/1s used for synchronization
    2. Start Frame Delimiter (SFD): 1 byte: designates end of Preamble
    3. Destination MAC address: 6 bytes
    4. Source MAC address: 6 bytes
    5. EtherType: 2 bytes: payload metadata
    6. Payload: 46-1500 bytes (9000 with jumbo frames)
    7. Frame Check Sequence (FCS): 4 bytes: CRC checksum

    Cyclic Redundancy Error (CRC):
    - add a FCS to the end of an Ethernet frame
    - receive the frame, recalculate the CRC, compare to original
    - non matching means an error -> CRC counter incremented
    Runts: frames that are less than 64 bytes
        - likely result of collision
    Giants: frames that are more than 1518 bytes (or the configured maximum size)
    Drops: frames not transmitted or received due to contention (lost frames)


Disabling interfaces can be a simple way to stop a problem

Error Disabled: interface automatically disabled if problem detected
Many reasons can trigger this: link flapping (up/down), port security violations (new device plugged in), duplex mismatch
Need admin to re-enable on switch

Administratively down:
Admin turned off interface manually
Need admin to re-enable on switch

Suspended:
- configuration is not compatible with current connection
- e.g. Link Aggregration Control Protocol (LACP) set on one side, but not the other
