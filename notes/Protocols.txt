Internel Control Message Protocol (ICMP):
pinging between network devices
network responds: server down, TTL expired

Generic Routing Encapsulation (GRE):
"tunnel" between endpoints
Encapsulates traffic inside of IP
Not encrypted

VPN:
Concentrator
- encrytpion/decryption access device
Site to Site VPN
- always on
- firewalls act as Concentrators

Internet Protocol Security (IPSec):
- security for layer 3 (Network)
- Encryption and packet signing (Confidentiality and integrity)
- Standardized accross vendors
AH and RDP

Internet Key Exchange (IKE):
- agree on encryption/decryption keys without sending them across the network (builds a security association - SA)
Phase 1
- use Diffie-Hellman to create shared secret key
UDP/500
Internet Security Assocation and KEY Management Protocol (ISAKMP)

Phase 2
Coordinate ciphers and key sizes
negotiate an inbound and outbound SA for IPSec

Authentication Header:
hash of packet and shared key (ensures integrity only)

Encapsulation Security Payload (ESP):
encrypts packet (IP header and data, along with ESP trailer)
