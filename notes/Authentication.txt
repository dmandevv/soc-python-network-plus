AAA framework:
Identification - who you claim to be
Authentication - prove who you claim to be
Authorization - what access do you have
Accounting - log resources used - login time

Single sign-on (SSO):
- provide credentials once
- usually limited by time (every 24hrs)
- not always an option for Authentication

Remote Authentication Dial-in User Service (RADIUS):
- AAA protocol
- centralized Authentication for users
- can be used to Authenticate for many Services:
    1. routes, switches, firewalls
    2. servers
    3. remote VPN access (concentrator)
    4. 802.1X network access

Lightweight Directory Access protocol (LDAP):
- protocol for reading and writing directories over an IP network
- X.500 specification
- Lightweight version of Directory Access protocol (DAP)
- LDAP is the protocol used to query and update an X.500 directory (Windows Active Directory)

X.500 Distinguished Names:
Common Name (CN): identifies person/object
Organization Unit (OU): unit/department within an Organization
Organization (O): name of Organization
Locality (L): city/area
State (ST): state/province
Country (C): country's 2-character ISO code (CA, US, GB)
Domain Component (DC): parts of domain object belongs to (DC=google, DC=com)


Security Assertion Markdown Language (SAML):
- open standard for authentication and authorization 
- auth through a 3rd party
- wasn't designed for mobile
1. user tries to access a Resource Server
2. is redirected with a signed/encrypted SAML request to an Authorization Server
3. User logs into Auth. Server
4. Auth is successful, SAML token is generated
5. User can present SAML token to Resource Server
6. SAML token is verified, access granted

Terminal Access Controller Access-Control System (TACACS):
- remote auth. protocol
- created to control access to dial-up lines to ARPNET
TACACS+ is latest version, not backwards compatible, added more auth. requests and response codes, open standard as of 1993


Time-based One-Time password algorithm (TOTP):
- uses a secret key and time of day, non incremental
- secret key is configured ahead of time
- timestamps synced with NTP
- timestamps increment every 30s
