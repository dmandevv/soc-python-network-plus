Classful subnetting:


PRACTICE 1

IP Address 10.74.222.11
Class A!
Subnet mask is 255.0.0.0

Network bits: 10.
Host bits: 74. 222. 11

Subnet calculation:

1. Network Address (set all host bits to 0)
10.0.0.0

2. First host address (add one to Network address)
10.0.0.1

3. Broadcast address (set all host bits to 1)
10.255.255.255

4. Last host address (subtract one from Broadcast address)
10.255.255.254
