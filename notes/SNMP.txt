Simple Network Management Protocol (SNMP):
- database of data (MIB) - Management Information Base
- database contains OIDs - Object Identifiers
- Poll devices over UDP/161

SNMP v1
- structured tables in-the-clear

SNMP v2c
- data type enhancements, bulk transfers, still in-the-clear

SNMP v3
- message integrity, authentication, encryption

SNMP OIDs:
- object Identifiers can referenced by name or number
- every variable in MIB has a corresponding OID 
- some are common, others are manufacturer specific

Walking the SNMP MIB:
- get all MIBs for a device

SNMP traps:
- most SNMP operations expect a poll (at a set interval, e.g. 5 mins)
- devices then respond to the SNMP request
- this requires constant polling

SNMP traps can be configured on the monitored device:
- communicates over UDP/162
- set thresholds for alerts
    - e.g. if the number of CRC errors exceeds 5, send a trap 
    - monitoring station can react immediately

Authentication:

- Community String:
    - simple password
    - read-only, read-write, trap
    - common strings: "public" and "private"
    - used with SNMP v1 and v2c

- Username and password:
    - used in SNMP v3
    - transmitted as password hash
